The heart of the vault. Every skill lives here as a fully structured database entry with the following fields:

| Field | Type | Description |

|---|---|---|

| Skill Name | Title | Clear, action-oriented name (e.g., *Cold Email Personalizer*) |

| Category | Select | Sales / Marketing / Ops / HR / Finance / Support / Legal / Product |

| Complexity | Select | Beginner / Intermediate / Advanced |

| Status | Select | ✅ Deployed / 🧪 Testing / 📋 Queued / ⚠️ Needs Update |

| AI Tool | Multi-select | ChatGPT / Claude / Gemini / Copilot / Perplexity |

| Time Saved (hrs/week) | Number | Track ROI per skill |

| Prompt Template | Text | Full prompt with `[VARIABLES]` clearly marked |

| Use Case Description | Text | 2–3 sentence summary of what the skill does and when to use it |

⚡ Get Started in 3 Minutes

Follow these four steps and you'll have your first AI skill deployed before your next coffee break:

Step 1 — Duplicate the Template

> Click the "Duplicate" button in the top-right corner of the Notion page. Select the workspace you want to save it to. The entire vault — all databases, views, and content — will be copied to your account instantly.

Step 2 — Browse the Skills Library

> Open the AI Skills Library database. Use the Category or Complexity filters to find a skill relevant to your immediate needs. Not sure where to start? Sort by Time Saved (hrs/week) to find the highest-impact skills first.

Step 3 — Open a Skill & Copy the Prompt

> Click into any skill entry. Read the Use Case Description to confirm it fits your need. Copy the Prompt Template and replace all `[VARIABLES]` in brackets with your specific information (e.g., `[COMPANY NAME]`, `[TARGET AUDIENCE]`, `[TONE]`).

Step 4 — Deploy & Track

> Paste your customized prompt into your AI tool of choice (ChatGPT, Claude, Gemini, etc.). Once you're happy with the output, update the skill's Status to ✅ Deployed and log your estimated Time Saved (hrs/week) to start tracking your ROI.

> 💡 Pro tip: Start with 3–5 skills from your primary department before expanding. Depth beats breadth when building AI habits.

❓ Frequently Asked Questions

Q1: Do I need to know how to write prompts to use this template?

> No. Every skill comes with a fully written, ready-to-use prompt template. You only need to replace the clearly marked `[VARIABLES]` with your own context. No prompt engineering knowledge required — that's the whole point.

Q2: Which AI tools are compatible with these skills?

> The skills are designed to work across all major AI tools including ChatGPT, Claude, Gemini, Microsoft Copilot, and Perplexity. Each skill entry specifies which tools it's been tested and optimized for, so you always know where to deploy it.

Q3: Can I add my own custom skills to the vault?

> Absolutely. The database is fully editable — just create a new entry and fill in the fields. The structure is designed to be extended. You can add your own prompts, categories, and notes without breaking anything.

Q4: Is this a one-time purchase or a subscription?

> This is a one-time template duplication. Once you've copied it to your Notion workspace, it's yours permanently with no recurring fees. Any future updates to the original template will be communicated via email to registered users.

Q5: What if a prompt doesn't perform well for my specific use case?

> Start by reviewing the Prompt Engineering Notes section attached to each skill — these explain the reasoning behind the structure and give you a clear path to modify it. You can also update the skill's Status to ⚠️ Needs Update and use the Testing Tracker view to iterate systematically until it performs to your standard.
